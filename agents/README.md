# Семь исследовательских агентов

Все роли работают под координацией Ruflo. Каждая роль отвечает за свой тип данных и передаёт результат следующему этапу. Роль не даёт дополнительных прав на публикацию.

- [Региональный разведчик](regional-scout.md)
- [Ихтиологический исследователь](ichthyology-researcher.md)
- [Географ](geographer.md)
- [Аналитик условий](conditions-analyst.md)
- [Фотоисследователь](photo-researcher.md)
- [Верификатор](verifier.md)
- [Главный редактор](chief-editor.md)

Общий формат результата: регион и водоём; проверяемые факты; источники; даты; уверенность A–D; противоречия и неизвестное; рекомендации; статус задачи.
