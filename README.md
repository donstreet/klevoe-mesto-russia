# Клёвое место — всероссийская рыболовная платформа

Самостоятельный проект всероссийского портала «Клёвое место». Репозиторий предназначен для архитектуры, документации, планирования, разработки и безопасного выпуска изменений.

## Принципы проекта

- **Россия и регионы:** единая платформа с региональным контекстом. Выбор региона определяет водоёмы, чаты, магазины, объявления, места отдыха и другие региональные данные.
- **Сначала проверка:** изменения разрабатываются и проверяются в Preview. Production не является экспериментальной площадкой.
- **Никаких выдуманных данных:** сведения о водоёмах, рыбе, правилах, ценах, подъездах и происшествиях сопровождаются источниками и уровнем уверенности.
- **Безопасность пользователей:** нельзя терять существующие аккаунты, сообщения, объявления и данные. Миграции и изменения схемы требуют плана, резервной копии и проверки восстановления.
- **Разделение полномочий:** исследование, подготовка и тестирование не дают права самостоятельно публиковать изменения в Production.
- **Публичный репозиторий:** здесь запрещены пароли, токены, API-ключи, приватные данные пользователей, дампы БД и внутренние адреса/секреты инфраструктуры.

## Текущая инфраструктурная граница

- Основной портал: https://fishrusss.duckdns.org
- Основной сервер портала: 137.22.151.247
- Отдельный VPS в Нидерландах предназначен для AI-команды и автоматизации: Ruflo, AI Router, n8n и Browser Tester.
- AI-инфраструктура не должна подменять или напрямую изменять Production портала.
