# 04. Автономная работа и уровни разрешений

## Цель
AI-команда работает непрерывно и самостоятельно выполняет безопасные повторяемые задачи. Автономность ограничена правами и не означает бесконтрольный доступ к данным и Production.

## Уровни
- **L0 — Наблюдение:** чтение разрешённых источников, диагностика, сбор статусов, отчёты. Никаких изменений.
- **L1 — Подготовка:** черновики, карточки, ответы, планы, тест-кейсы и изменения в изолированной ветке. Никакой публикации в Production.
- **L2 — Безопасная автоматизация:** повторяемые действия в тестовой среде и утверждённые процессы: классификация обращений, подготовка ответов, проверка заполнения, уведомления, запуск тестов. Всё журналируется.
- **L3 — Ограниченное выполнение:** публикация только типов материалов, для которых владелец отдельно утвердил правила, критерии и границы. При сомнении — остановка и эскалация.
- **L4 — Только владелец/уполномоченный человек:** изменения Production, миграции, финансы, блокировки, удаление данных, изменение ролей/прав, системные настройки, секреты и необратимые действия требуют явного разрешения.

## Матрица разрешений
| Действие | Агент по умолчанию |
|---|---|
| Поиск и анализ публичных источников | Разрешено |
| Черновик карточки водоёма | Разрешено |
| Независимая проверка карточки | Разрешено |
| Создание материала в исследовательской БД | Только выделенная область |
| Изменение Preview | По задаче и с журналом |
| Ответ на типовое обращение | По утверждённому шаблону/правилам |
| Открытие магазина/кабинета | Подготовка и проверка; активация по правилам владельца |
| Публикация в Production | Отдельное разрешение |
| Бан пользователя | Только с человеком |
| Финансовые операции/возвраты | Только с человеком |
| Удаление пользовательских данных | Только с человеком |
| Изменение системных настроек/секретов | Только с человеком |

## Предохранители
Минимальные привилегии; раздельные тестовые и боевые ключи; подтверждение владельца для рискованных операций; идемпотентность; лимиты расходов и частоты; остановка при конфликте данных или подозрении на утечку; журнал действий; возможность отката и восстановления.

## Режим 24/7
n8n запускает задачи по расписанию и событиям. Ruflo распределяет их и контролирует таймауты, повторы и блокировки. Неуспешные задачи не должны бесконечно повторяться или создавать дубликаты. Критические ошибки направляются владельцу.
