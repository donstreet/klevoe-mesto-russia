# 10. Основа приложения и технологический стек

## Утверждённая стартовая конфигурация
- Next.js App Router и React — web-приложение и серверные маршруты.
- TypeScript — строгая типизация.
- Tailwind CSS 4 — стилизация и адаптивная дизайн-система.
- PostgreSQL — основная реляционная БД.
- Prisma — планируемый ORM-слой, добавляется вместе с первой миграцией после согласования схемы.
- Zod — проверка входных данных на границах API.
- Vercel — Preview deployments по веткам/PR после подключения проекта.

## Структура
- src/app — маршруты и layout.
- src/components — переиспользуемые UI-компоненты (добавляется по мере появления).
- src/features — функциональные модули портала (добавляется по мере появления).
- src/lib — инфраструктурные клиенты и общие функции (добавляется по мере появления).
- docs — продуктовая и техническая документация.
- agents — инструкции специализированных AI-ролей.

## Первый этап
Создана базовая русскоязычная главная страница с направлением дизайна «Лесная бирюза», адаптивной сеткой и честными статусами незапущенных разделов. Это визуальный каркас, а не готовый портал: авторизация, база данных, региональный справочник, чаты и административные функции ещё не подключены.

## Следующие этапы
1. CI: установка зависимостей, lint, typecheck и build.
2. Подключение Vercel Preview к отдельному проекту.
3. Согласование схемы регионов, пользователей и водоёмов.
4. Подключение PostgreSQL и Prisma миграций.
5. Авторизация и роли.
6. Региональный контекст и каталог водоёмов.
7. Остальные продуктовые разделы.

Production-портал не подключать к этой заготовке до отдельного плана миграции и сохранения действующих аккаунтов/данных.
